# proxima
a simple software backlight controller for windows.

I made this because the default windows brightness doesn't work well on my cloud desktop. 
It basically just puts a black transparent overlay over your screen to dim it instead of touching the actual hardware monitor settings.

How to use:
Download the zip file, extract it and just double click the `proxima.exe` file. it'll run in the backround and add itself to your startup apps automatically.

hotkeys:
ctrl + f7 = dim the screen
ctrl + f8 = increase brightness

to close it, just right click the icon in your system tray and hit exit.
